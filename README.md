# Reet
## Multithreading, Concurrency, and Game Logic

This repository contains our team's source code, documentation, and visualizations for the four core implementation assignments. The project encompasses multithreaded search engine analysis, practical Java concurrency applications, and game logic development.

## Project Scope

### Assignment 1: Multithreaded SERP Analysis
Design and implementation of a multithreaded program for processing Search Engine Results Pages (SERP). This module is split into two distinct extraction tasks:
* **Crime-Reporting Papers:** Extracts and returns at least 10 distinctive features from SERPs, categorizing them in order of the number of systems having the feature. This implementation includes data visualization of the results.
* **Deep Learning Models:** Extracts distinct sub-headings from journal papers focused on deep learning. This implementation includes data visualization of the results.

### Assignment 2: Java Concurrency
* **Tracking Fleet Vehicles:** Direct implementation of the "Tracking Fleet Vehicles" example detailed in section 4.2.2 of *Java Concurrency In Practice* by Brian Goetz et. al.

### Assignment 3: Ayo Game
* **Description and Implementation:** The complete structural description and programmatic implementation of the *Ayo* game.

### Assignment 4: Dead or Wounded Game
* **Description and Implementation:** The complete structural description and programmatic implementation of the *dead or wounded* game.
